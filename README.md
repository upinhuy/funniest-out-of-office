# The Funniest Out-of-Office

Entry for the make.fun bounty
[u-kreutzx-the-funniest-out-of-office-054815cf](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf):
a single line of out-of-office auto-reply, the funniest one line can hold,
in 140 characters or fewer. No image, no link, no second line.

`main.ts` writes the line to `/output/entry.txt`:

> I'm out of office until Monday. This auto-reply is now in charge of my inbox — it has no password, no patience, and one job: saying no.

Run it with Node 22:

```sh
node main.ts
```
